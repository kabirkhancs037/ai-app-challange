# AMERICA'S BEHAVIORAL POLITICAL MAP
AI-powered audience intelligence platform for exploring, comparing, and analyzing behavioral voter archetypes across the United States.

## Features

### Behavioral Political Map
* Interactive voter archetype clustering
* Filter by region, demographics, income, and ethnicity
* Dynamic population and persuadability metrics
* Geographic audience visualization

### Archetype Explorer
* Demographics and behavioral DNA
* Political profile and issue affinity
* Geographic concentration
* Persuadability analysis
* Coalition overlap insights

### AI Discovery
* "What Surprised Me?" AI-generated audience insights
* Real-time analysis using archetype profile data
* Unexpected behavioral and political findings

### Compare Archetypes
* Side-by-side archetype comparison
* Demographic and behavioral analysis
* Political issue comparison
* AI-generated comparison insights
* Strategic audience takeaways

### AI Strategist
* Audience summaries
* Messaging recommendations
* Persuasion strategies
* Activation planning

## Local Setup

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
```

### Deployment

Frontend:
* Vercel
* Static React build via Vite

Backend:
* Node.js / Express API
* REST-based AI endpoints

Example API endpoints:
* POST /api/strategist-chat
* POST /api/surprising-insight


### Environment Variables
```env
PORT=5050

AI_PROVIDER=ollama

OPENAI_API_KEY=YOUR_OPENAI_KEY
GEMINI_API_KEY=YOUR_GEMINI_KEY

VITE_API_URL=http://localhost:5050
```
